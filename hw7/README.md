# Homework 7: Objects and functional programming

This folder contains the public assignment contract and the exact PHPUnit tests Ed runs for Homework 7. The tests are meant to make the grading behavior visible; they do not contain completed solutions.

| Assignment | Public test | Behaviors graded |
| --- | --- | --- |
| `reduce()` | `reduceTest.php` | named and anonymous callbacks, accumulator argument order |
| `modeMaker()` | `2modeMakerTest.php` | a basic mode, a changing mode, independent closure state |
| `Car` | `1classCarTest.php` | construction, driving, fuel limits, accumulated state, adding gas |

Students do not need to download or submit these tests. In Ed, each visible test category runs the correspondingly named PHPUnit method.
