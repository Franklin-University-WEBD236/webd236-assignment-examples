# Contributing

Keep assignment requirements and tests synchronized.

1. Describe the observable requirement in the assignment contract.
2. Add or update a narrowly focused test with a useful failure message.
3. Avoid requiring an internal implementation detail unless that detail is a learning objective.
4. Keep test inputs deterministic and independent of external Internet services.
5. Run PHP syntax checks before opening a pull request.

Ed point values, testcase JSON, course identifiers, and deployment-only files belong in the private autograding repository.
