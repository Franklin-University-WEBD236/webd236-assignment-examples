# Homework 2

Homework 2 contains two kinds of automated work:

- [`sql/`](sql/) documents three SQL result contracts and provides a second dataset that prevents solutions from working only for the original rows.
- [`faculty/`](faculty/) documents and tests the employee list and employee-detail pages.

The SQL grader enforces row order, column order, and column names. The PHP tests invoke the pages through the included request harness.
