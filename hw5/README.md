# Homework 5: String functions

This folder contains the public assignment contract and the exact PHPUnit tests Ed runs for Homework 5. The tests are meant to make the grading behavior visible; they do not contain completed solutions.

| Assignment | Public test | Behaviors graded |
| --- | --- | --- |
| `isLetter()` | `isLetterTest.php` | uppercase, lowercase, ASCII boundaries, invalid lengths and characters |
| `myReverse()` | `myReverseTest.php` | ordinary text, palindromes, short inputs, spaces and punctuation |
| `isPalindrome()` | `isPalindromeTest.php` | simple palindromes, ignored non-letters, case, negative cases |
| `countdownFront()` | `countdownFrontTest.php` | values from 0 through the full string length |
| `longestRun()` | `longestRunTest.php` | consecutive runs, separated repeats, empty and one-character strings |

Students do not need to download or submit these tests. In Ed, each visible test category runs the correspondingly named PHPUnit method.
